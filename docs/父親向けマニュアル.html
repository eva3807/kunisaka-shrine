サイト更新の手引き

お知らせ・授与品・御朱印・行事のご案内を、パソコンから書き換えるための手順書です。難しい操作はありません。文字を打ち込んで、最後に一度だけ保存するだけです。

1. はじめに ― 管理画面を開く

更新はすべて「管理画面」という一つの画面から行います。毎回この手順で開いてください。

アカウントについて

登録の手続きはすでに済ませてあります。ご自分で新しく作る必要はありません。お渡ししたログイン用の名前と合言葉を、そのままお使いください。

  1. パソコンでインターネットを開き、住所の欄に app.pagescms.org と入力します。
    （下のQRコードを携帯電話で読み取っても開けます）
  2. Sign in with GitHub （ギットハブでログイン）を押します。
  3. お渡しした名前と合言葉を入れて進みます。
    「許可しますか」といった確認が出たときは、緑色のボタンを押してください。
  4. 一覧から kunisaka-shrine を選びます。

QRコードは、携帯電話のカメラを向けるだけで読み取れます。画面に出た文字を押すと、そのまま開きます。

画面の左側に、書き換えられる項目が並びます。これが目次にあたります。

左の項目書き換わる場所
お知らせトップページのいちばん上の欄
授与品お守り・お札・破魔矢などのご案内
御朱印初穂料・受付時間・限定御朱印

画面の言葉について

入力欄の名前（日付・見出し・本文など）は日本語ですが、ボタンの一部は英語です。よく使うのは Save（保存）だけです。項目の見出しに Item #1 のような英語が出ますが、「1つめ」という意味なので気にしなくて構いません。

2. 更新の流れ

どの項目を直す場合も、流れは同じです。

管理画面をひらく
▼
左から項目をえらぶ
▼
文字を打ちなおす
▼
右上の Save を押す
▼
５分ほど待つ神社のサイトが自動で書きかわります
大切なこと

Save を押さないと、何も変わりません。打ち込んだだけでは保存されていません。書き終えたら必ず押してください。

3. お知らせを出す

「本日は社務所を閉めます」「七五三の受付を始めました」など、参拝の方へのお知らせです。トップページのいちばん目立つ場所に出ます。

  1. 左から お知らせ を選びます。
  2. いちばん下にある ＋ または Add を押して、新しい欄をつくります。
  3. 日付 … カレンダーから今日の日付を選びます。
  4. 見出し … ひと目で分かる短い題を入れます。
    例：七五三のご祈祷を承っております
  5. 本文 … くわしい内容を書きます。何行でも構いません。
  6. 重要 … 特に目立たせたいときだけ、つまみを右にします。赤い帯と「重要」の印が付きます。
  7. 公開する … 右（緑）になっていることを確かめます。
  8. 右上の Save を押します。

新しいお知らせは、日付の新しい順に自動で上へ並びます。順番を気にする必要はありません。

4. 授与品を載せる（正月など）

お守り・お札・破魔矢などのご案内です。正月だけの授与品も、この項目に登録して期間を入れておきます。

  1. 左から 授与品 を選びます。
  2. ＋ を押して新しい欄をつくります。
  3. 名称 … 授与品の名前を入れます。例：破魔矢
  4. 区分 … 「常時」「正月限定」「期間限定」から選びます。選んだ言葉がそのまま札のように表示されます。
  5. 初穂料 … 「1000円」のように書きます。
    金額を出したくないときは空欄のままで構いません。
  6. 授与開始日・授与終了日 … 期間が決まっているものだけ入れます。常時のものは空欄で結構です。
  7. 説明 … どのようなお守りかを書きます。
  8. 写真 … 入れ方は「7. 写真を入れる」をご覧ください。無くても構いません。
  9. 公開する を右（緑）にして、Save を押します。
来年も使えます

正月が終わったら、消さずに 公開する を左（灰色）にしてください。サイトからは消えますが記録は残るので、来年また右に戻すだけで再び載せられます。作り直す必要はありません。

5. 予定・連絡を載せる（境内清掃など）

「9月13日に境内清掃をします」といった、日付が決まっている連絡です。ここに入れると、行事カレンダーと「次の行事・お知らせ」の両方に自動で出ます。

  1. 左から 予定・連絡 を選びます。
  2. ＋ を押して新しい欄をつくります。
  3. 日付 … 実施する日をカレンダーから選びます。
  4. 時間 … 「8:00〜10:00」のように書きます。決まっていなければ空欄で構いません。
  5. 件名 … 「境内清掃」「氏子総会」など。
  6. 種別 … 清掃奉仕・祭典・会合・お知らせ・その他 から選びます。
  7. 場所・内容 … 分かる範囲で入れます。
  8. 公開する を右（緑）にして、Save を押します。

「年中行事」との使い分け

登録したいもの使う項目
毎年決まっている祭典（例大祭・歳旦祭など）年中行事
今年だけの予定（境内清掃・総会・臨時の祭典）予定・連絡

同じ行事を両方に入れてしまっても、サイトの上では自動で一つにまとめて表示されます。間違いにはなりませんのでご安心ください。

日が過ぎた予定

日付が過ぎたものは「次の行事」から自動で消えます。放っておいても古い予定が残り続けることはありません。

6. 御朱印の案内を直す

初穂料や受付時間は、いまは「社務所にてお尋ねください」となっています。実際の金額・時間を出す場合はここを書き換えます。

  1. 左から 御朱印 を選びます。
  2. 初穂料・受付時間・受付場所 の欄を、実際の内容に書き換えます。
  3. 限定の御朱印を出すときは、下の 限定御朱印 の欄に名称・頒布期間・初穂料を入れ、公開する を右にします。
  4. Save を押します。

7. 写真を入れる

  1. あらかじめ、パソコンに写真を用意しておきます。
  2. 入力欄の中の 写真 の場所を押します。
  3. ファイルを選ぶ画面が出たら、載せたい写真を選びます。
    （写真をそのまま枠の上にドラッグしても入ります）
  4. 小さな見本が表示されれば入っています。
  5. Save を押します。
写真のこつ

横向き（横長）の写真がきれいに収まります。スマートフォンで撮った写真もそのまま使えます。うまく入らないときは、無理をせず写真なしで保存しても構いません。文字だけでも問題なく表示されます。

8. いったん隠す・並び替える

隠す（消さずに見えなくする）

どの項目にも 公開する というつまみがあります。

  • 右（緑） … サイトに表示されます
  • 左（灰色） … サイトから消えますが、記録は残ります

季節のもの、終わった行事は消さずに左にしておくのがおすすめです。翌年また右に戻すだけで使えます。

並び順を変える

並び順 という数字の欄があります。数字の小さいものが先に表示されます。いちばん上に出したいものを 1、次を 2、というように入れてください。

「お知らせ」だけは日付の新しい順に自動で並ぶため、この欄はありません。

9. 保存したあと

  1. Save を押します。
  2. 5分ほど待ちます。この間に、機械が自動でサイトを作り直しています。
  3. 神社のサイトを開いて、変わったことを確かめます。
    eva3807.github.io/kunisaka-shrine/
    （前ページのQRコードからも開けます）
変わっていないように見えるとき

まだ作り直しの途中かもしれません。もう5分待ってから、キーボードの Ctrl を押しながら F5 を押してください。画面が新しく読み込み直されます。

こんなときどうするか
保存しても
サイトが変わらない		 まず10分待ちます。それでも変わらなければ、そのままにして連絡してください。何度も保存し直す必要はありません。
間違えて保存した あわてなくて大丈夫です。書き換えの記録はすべて残っており、いつでも元に戻せます。連絡してください。
間違えて消した 同じく元に戻せます。ご自分で直そうとせず、そのままにしておいてください。
ログインできない 画面を一度閉じて、もう一度 app.pagescms.org から開き直してください。それでも入れなければ連絡してください。
英語の画面が出て
分からない		 むやみに押さず、画面をそのままにして写真を撮っておいてください。何が出ているかが分かれば対応できます。
画面の見た目を

迷ったら

何もせずそのままにしておくのが、いちばん安全です。この仕組みは、書き換えの記録がすべて残るようになっています。壊れて取り返しがつかなくなることはありません。

11. しなくてよいこと

次のことは、いっさい気にしなくて構いません。

  • バックアップを取る … 自動で記録が残ります
  • 英語の画面や記号の意味を調べる … 使うのは日本語の欄だけです
  • サイト基本情報 の「Googleマップ埋め込みURL」を直す … 触らなくて結構です
  • 「内部メモ」と書かれた欄 … サイトには出ません。空欄のままで構いません
  • 作業をまとめてから保存する … 一つ直すごとに保存して構いません

覚えておくのは三つだけ

  • 一app.pagescms.org から入る
  • 二書き終えたら、右上の Save を押す
  • 三困ったら、そのままにして連絡する
